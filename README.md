# Papa's Burgeria DS Demake

**⚠️ This project was created with AI assistance using GitHub Copilot** 🤖

A Nintendo DS/DSi demake of Papa's Burgeria featuring burger assembly with **touch screen controls**, customer order management, and time-based cooking mechanics.

## Game Features

- **Touch Screen Controls**: Use the stylus to tap ingredients and serve burgers
- **Burger Assembly**: Add patties, lettuce, tomato, cheese, and onion to create custom burgers
- **Order Management**: Customers arrive with burger orders; fulfill them before they leave
- **Time Pressure**: Complete orders quickly to earn bonuses and keep customers happy
- **Progressive Difficulty**: Levels increase in difficulty with faster-paced orders
- **Score System**: Earn money and points for correct orders
- **Graphics**: Sprite-based visual representation of burgers (no ASCII art!)

## Controls (Touch Screen)

| Button | Action |
|--------|--------|
| **Patty** | Add Patty to burger |
| **Lettuce** | Toggle Lettuce |
| **Tomato** | Toggle Tomato |
| **Cheese** | Toggle Cheese |
| **Onion** | Toggle Onion |
| **Serve** | Serve the burger to customer |
| **New Order** | Generate a new order |
| **Start** | Start the game from menu |

## How to Play

1. Start the game by tapping "Start" on the menu
2. Look at the customer's order displayed on screen
3. Tap ingredients on the bottom screen to assemble the burger
4. Tap "Serve" to give the burger to the customer
5. Complete orders correctly before the wait timer runs out
6. Earn money and advance to harder levels

## Game Mechanics

- **Correct Order**: +100 points + time bonus
- **Wrong Order**: -50 points
- **Missed Order (timeout)**: -75 points
- **Difficulty increases**: Each level reduces customer patience
